# CachimdIA V4 REAL

Versión visual reconstruida desde cero para parecerse al mockup móvil: splash peruano con emoliente, módulos 2x2 con Paddy, examen tipo Duolingo, camino gamificado con metas UNSA/UCSM/UCSP, desempeño y recursos.

## Ejecutar
npm.cmd install
npm.cmd run dev

Puerto por defecto: http://localhost:5190/

No usa service worker, para evitar que el navegador muestre una versión antigua en caché.
